魚ごとのランカーサイズの目安まとめ
尺メバル・座布団ヒラメ・年無しチヌは何cmから？

「ランカーって何cmから？」「尺メバルってどのくらい？」という疑問に答えるために、ルアーで狙う魚14種類の、よく釣れるサイズと大物の目安を表にまとめました。
釣り人の間で使われる大物の呼び名と、そのサイズの目安、最大でどのくらいまで大きくなるかを紹介します。自分の釣った魚がどのくらいのサイズなのか、チェックしてみてください。

魚ごとのランカーサイズ

シーバス（スズキ）

よく釣れるサイズ40〜60cm
大物の呼び名とサイズランカー：80cm以上
最大サイズの目安1m超
JGFA日本記録（重さ）13.14kg（2006年・大分県堅田川）

80cmを超えると「ランカー」と呼ばれ、多くのシーバスアングラーの目標になります。ベイトが多い秋や、河川の大型が狙えるタイミングにチャンスがあります。

ブリ（青物）

よく釣れるサイズ40〜70cm
大物の呼び名とサイズブリ：80cm以上（関西ではメジロの次）
最大サイズの目安1m超
JGFA日本記録（重さ）22.10kg（2005年・三重県石鏡沖）

出世魚で、関西ではツバス→ハマチ→メジロ→ブリと呼び名が変わります。ショアから80cmを超えるブリが釣れたら大物です。

青物のルアーを図鑑で見る

サワラ

よく釣れるサイズ50〜80cm
大物の呼び名とサイズメーターサワラ：1m以上
最大サイズの目安1m超
JGFA日本記録（重さ）10.57kg（2015年・長崎県五島列島）

50cm前後までは「サゴシ」、それより大きいと「サワラ」と呼ばれます。船のブレードジギングでは、1mを超える「メーターサワラ」も夢ではありません。

サワラのルアーを図鑑で見る

タチウオ

よく釣れるサイズ指3本（幅約3cm）
大物の呼び名とサイズドラゴン：指5本以上
最大サイズの目安1.5m前後
JGFA日本記録（重さ）5.13kg（2020年・鹿児島県鹿屋高須沖）

タチウオは長さではなく、体の幅を「指何本分か」で表します。指5本を超える大型は「ドラゴン」と呼ばれます。

タチウオのルアーを図鑑で見る

アオリイカ

よく釣れるサイズ秋：200〜500g
大物の呼び名とサイズキロアップ：1kg以上
最大サイズの目安3kg超
JGFA日本記録（重さ）登録なし

重さで表すのが一般的です。春の親イカは1kgを超える「キロアップ」が狙え、2kgを超えると自慢のサイズです。

ヒラメ

よく釣れるサイズ40〜60cm
大物の呼び名とサイズ座布団ヒラメ：70cm以上
最大サイズの目安1m前後
JGFA日本記録（重さ）14.50kg（2008年・島根県隠岐郡西ノ島町）

40cmより小さいものは「ソゲ」、70cmを超える大型は、座布団のような大きさから「座布団ヒラメ」と呼ばれます。

マゴチ

よく釣れるサイズ40〜50cm
大物の呼び名とサイズランカー：60cm以上
最大サイズの目安70cm超
JGFA日本記録（重さ）2.50kg（2009年・大分県大野川）

60cmを超えると大型。大きいマゴチはほとんどがメスで、夏のサーフや河口で狙えます。

フラットフィッシュのルアーを図鑑で見る

チヌ（クロダイ）

よく釣れるサイズ30〜45cm
大物の呼び名とサイズ年無し：50cm以上
最大サイズの目安60cm超
JGFA日本記録（重さ）4.25kg（2010年・大阪府大阪湾南港南）

50cmを超えるチヌは、年齢がわからないほど長生きした魚という意味で「年無し」と呼ばれます。

アジ

よく釣れるサイズ15〜25cm
大物の呼び名とサイズ尺アジ：30cm以上（ギガアジ：40cm以上）
最大サイズの目安50cm前後
JGFA日本記録（重さ）1.19kg（2010年・三重県古和浦沖）

約30cm（1尺）を超えると「尺アジ」、40cmを超えると「ギガアジ」と呼ばれます。

ライトゲームのルアーを図鑑で見る

メバル

よく釣れるサイズ15〜20cm
大物の呼び名とサイズ尺メバル：30cm以上
最大サイズの目安30cm台
JGFA日本記録（重さ）アカメバル1.12kg／シロメバル0.95kg／クロメバル0.80kg

25cmを超えれば大型、30cm（1尺）を超える「尺メバル」はめったに釣れない憧れのサイズです。

ライトゲームのルアーを図鑑で見る

ガシラ（カサゴ）

よく釣れるサイズ15〜20cm
大物の呼び名とサイズ大型：25cm以上
最大サイズの目安30cm台
JGFA日本記録（重さ）0.77kg（2024年・長崎県五島列島防波堤）

成長がゆっくりな魚で、25cmを超えると大型。30cmを超えるものは「尺ガシラ」と呼ばれます。

よく釣れるサイズ25〜35cm
大物の呼び名とサイズ大型：40cm以上
最大サイズの目安60cm前後
JGFA日本記録（重さ）3.58kg（2020年・大分県佐賀ノ関沖）

40cmを超えると大型。成長が遅く、大きなアコウは何年もかけて育った貴重な魚です。

マダコ

よく釣れるサイズ300g〜1kg
大物の呼び名とサイズ大ダコ：2kg以上
最大サイズの目安3kg超
JGFA日本記録（重さ）登録なし

重さで表すのが一般的です。夏は数釣り、秋から冬は2kgを超える大ダコが狙える地域もあります。

よく釣れるサイズ30〜50cm
大物の呼び名とサイズ大ダイ：70cm以上（80cm以上は特大）
最大サイズの目安1m超
JGFA日本記録（重さ）11.60kg（2020年・茨城県鹿島灘）

70cmを超えると大型で、「大ダイ」と呼ばれます。春の乗っ込みは大型が浅場に集まるチャンスです。

出世魚の呼び名とサイズ

成長するにつれて呼び名が変わる魚を「出世魚」といいます。同じ魚でも地域によって呼び名が違うので、釣果情報を見るときの参考にしてください。

魚 関西の呼び名（小→大） 関東の呼び名（小→大）
ブリツバス → ハマチ → メジロ → ブリワカシ → イナダ → ワラサ → ブリ
スズキセイゴ → ハネ → スズキセイゴ → フッコ → スズキ
サワラサゴシ → ヤナギ → サワラサゴシ → ナギ → サワラ
チヌ（クロダイ）チンチン → カイズ → チヌチンチン → カイズ → クロダイ

どこからどの呼び名になるかは、地域や人によって幅があります。

大物を狙うコツ

  • 時期を選ぶ：多くの魚は、産卵前に体力をつける時期や、ベイトを追って荒食いする秋に大型が釣れやすくなります。魚ごとの時期は釣れる魚カレンダーで確認できます。
  • ルアーを大きくする：大きなルアーは小型の魚を避け、大型だけを選んで食わせやすくなります。数は減っても、1匹のサイズを上げたいときに有効です。
  • タックルを強めにする：大物が掛かったときに切られないよう、ラインとリーダーは少し太めに。ドラグもあらかじめ調整しておきましょう。
  • 大型が付く場所を知る：潮通しがよく、ベイトが集まる場所や、障害物の多い場所に大型は付きやすくなります。

サイズの正しい測り方

魚の長さの測り方には、主に「全長」と「尾叉長（びさちょう）」があります。

  • 全長：口の先から尾びれの先までの長さ。釣り人が「〇cm」と言うときは、ふつうこの全長です。
  • 尾叉長：口の先から尾びれの切れ込み（二股の分かれ目）までの長さ。ブリやサワラなどの研究や市場で使われます。

測るときは、魚の口を閉じて、メジャーの0cmに口先をそろえ、尾びれを自然に閉じた状態で測ります。メジャーは水でぬらしておくと、魚へのダメージを減らせます。リリースする魚は、写真を撮ったらすぐに海へ返しましょう。

よくある質問

「ランカー」ってどういう意味？

英語の「lunker（大物）」からきた言葉で、日本ではシーバスやブラックバスの大型によく使われます。シーバスでは80cm以上が目安です。

「尺」は何cm？

1尺は約30.3cmです。アジやメバル、ガシラなど、小型の魚で大物の目安として使われます。

大きな魚は持ち帰ってもいい？

大型の魚は、たくさんの卵を産む大切な親魚でもあります。持ち帰る数はほどほどにして、写真を撮ってリリースするのもおすすめです。小さな魚のリリースの目安は「関西のリリースサイズと抱卵時期まとめ」で紹介しています。

まとめ

  • シーバスは80cm以上がランカー、チヌは50cm以上が年無し、メバルとアジは30cm以上が尺、ヒラメは70cm以上が座布団。
  • タチウオは「指の本数」、アオリイカとタコは「重さ」でサイズを表すのが一般的。
  • 大物を狙うなら、時期・ルアーの大きさ・タックル・場所の4つを意識する。
  • サイズは口先から尾びれの先までの「全長」で測るのが基本。

狙う魚が決まったら、ルアー図鑑で大物に強いルアーもチェックしてみてください。
